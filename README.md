# NUDE ART STUDIO — V3

A mobile-first static gallery built for an artistic and educational fine-art context.

## Included in this package
- 47 curated Library-derived artworks (optimized WebP display copies)
- 9 collections: Figure Studies, Graphite & Charcoal, Anatomy & Movement, Classical & Renaissance, Couple Studies, Portraits & Expressions, Sculpture & Atelier, Drapery & Editorial, Movement & Pose
- Search, collection filters, style filters, sorting, grid/list view and load-more
- Fullscreen artwork viewer with keyboard navigation, mobile swipe and zoom
- Favorites saved locally on the device, Surprise Me, share link and recent-view record
- 18+ reminder, responsive mobile layout, lazy loading and no backend dependency

## Run locally
Open `index.html` in a modern browser. For the most reliable local experience, use a static server or GitHub Pages.

## Publish on GitHub Pages
1. Create a repository named `Nude-Art-Studio`.
2. Upload the contents of this ZIP to the repository root (not the ZIP itself).
3. Open Settings → Pages.
4. Under Build and deployment, select Deploy from a branch, branch `main`, folder `/(root)`, then Save.
5. Wait for GitHub Pages to finish publishing; the expected URL is `https://YOUR-USERNAME.github.io/Nude-Art-Studio/`.

## Content and rights notes
This package includes only a curated subset of Library images selected for artistic, educational, historical or non-explicit editorial context. Lingerie advertising, overtly erotic compositions and unrelated images were intentionally excluded from this GitHub-oriented build. Review every image, rights and consent before public release. The 18+ screen is only a reminder, not age verification.

GitHub's policy distinguishes artistic, educational and historical depictions from sexually obscene content, but GitHub retains discretion to limit content. Do not use this repository for pornography, graphic sexual acts or content whose primary purpose is to solicit an erotic response.
